Regression pipeline predicting California housing prices using XGBoost.
Full experiment tracking with MLflow.

## Results
| Metric | Value |
|--------|-------|
| MAE    | 0.31  |
| R²     | 0.83  |

## Tech stack
`Python` `XGBoost` `Pandas` `Seaborn` `Scikit-learn` `MLflow` `Jupyter`

## Setup
```bash
git clone https://github.com/ahmedyasser1588/California-Housing-Price-Prediction
cd California-Housing-Price-Prediction
pip install -r requirements.txt
jupyter notebook
```
